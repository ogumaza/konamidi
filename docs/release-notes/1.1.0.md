konamidi is now called supergbamidi, and this release reads Rare's sound driver as well as Konami's.
supergbamidi is a MIDI and SoundFont converter for Game Boy Advance games that use either driver.
It finds the driver in a ROM or GSF rip and plays each song through a model of that driver. Each
song gets a Standard MIDI File and a SoundFont built from the game's samples and instruments. For
Konami's driver, it also includes Game Boy PSG waveforms.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.gba`,
`.gsflib` or `.minigsf` files on `supergbamidi.exe`, or run it in a terminal; `supergbamidi --help`
lists the options. Each file's output goes in a folder next to it.

For macOS and Linux, follow the build instructions in the README. On macOS the build also makes
`Supergbamidi.app`, which you can drop files on in the Finder.

## Changes since konamidi 1.0.0

- The program is now `supergbamidi` (`supergbamidi.exe` on Windows), and the macOS app is
  `Supergbamidi.app`. The MIDI files and SoundFonts name supergbamidi as the program that made
  them.
- Rare's driver is supported, in the games listed under "Features".
- `--driver konami` or `--driver rare` reads a game with the driver you name, and `--info` names
  the driver it found.
- `--info` gives each song's length, loop and track count as its conversion would have them, with
  the loop played as many times as `--loops` says. konamidi's `--info` gave a looping song's
  length up to the end of its first loop, and for a few songs a different track count from the
  MIDI file's.

## Features

- **Games.** Five revisions of Konami's driver, from *Yu-Gi-Oh! Dungeon Dice Monsters* to
  *Yu-Gi-Oh! Ultimate Masters Edition: World Championship Tournament 2006*, and Rare's driver in
  *Donkey Kong Country*, *Donkey Kong Country 2*, *Banjo-Kazooie: Grunty's Revenge*,
  *Banjo-Pilot*, *Sabre Wulf* and *It's Mr. Pants*. Detection identifies each driver by its code,
  so other games using these revisions should work too.
- **MIDI.** With Konami's driver, one tick is one frame, so every event lands on the frame the
  game plays it, and volume, pan, pitch bend, vibrato and echo sends become MIDI controllers.
  With Rare's, each MIDI file keeps the tune's ticks, channels, keys, velocities, programs and
  volumes. The tempo is slowed to match the GBA's frame rate, and the driver's vibrato becomes
  pitch bends. Loops are marked with `loopStart` and `loopEnd`.
- **SoundFont.** Each song's SoundFont holds the instruments it uses: the game's samples at their
  own rates and loop points, Rare's drum kits, key splits and envelopes, and Konami's square
  and wave channel waveforms and noise generated from the Game Boy's LFSR.
- **Detection.** `--info` names the driver it found and lists the detected tables and any
  assumptions made during detection. `--driver` and the override options let you supply the
  driver and the table addresses yourself.

## Known limitations

- With Konami's driver, the Game Boy's PSG notes are written at equal-tempered pitch, although
  the hardware plays high notes slightly out of tune, and the driver's echo, a feedback delay, is
  approximated with the reverb send.
- Rare's driver mixes at most 8 voices at a time, while a SoundFont player plays every note. The
  SoundFonts' envelopes approximate the driver's straight-line fades, and its sound effects aren't
  converted.
- A SoundFont player resamples more cleanly than the GBA's mixer.
- Unsupported commands stop the affected track and produce a warning.
- See "Accuracy" in the README for the details.
