First release of konamidi, a MIDI and SoundFont converter for Game Boy Advance games that use
Konami's sound driver. It finds the driver in a ROM or GSF rip and plays each song through a
model of that driver. Each song gets a Standard MIDI File and a SoundFont built from the game's
samples and Game Boy PSG waveforms.

Requires 64-bit Windows 10 or later, with no additional runtime DLLs. Drop one or more `.gba`,
`.gsflib` or `.minigsf` files on `konamidi.exe`, or run it in a terminal; `konamidi --help`
lists the options. Each file's output goes in a folder next to it.

For macOS and Linux, follow the build instructions in the README. On macOS the build also makes
`Konamidi.app`, which you can drop files on in the Finder.

## Features

- **Games.** Five revisions of Konami's driver, from *Yu-Gi-Oh! Dungeon Dice Monsters* to
  *Yu-Gi-Oh! Ultimate Masters Edition: World Championship Tournament 2006*. Detection identifies
  the driver by its code, so other games using these revisions should work too.
- **MIDI.** One tick per frame, so every event lands on the frame the game plays it. Volume,
  pan, pitch bend, vibrato and echo sends become MIDI controllers, and loops are marked with
  `loopStart` and `loopEnd`.
- **SoundFont.** Each song's SoundFont holds the instruments it uses: the game's samples at their
  own rates and loop points, the square and wave channels' waveforms, and noise from the Game
  Boy's LFSR.
- **Detection.** `--info` lists the detected tables and any assumptions made during detection.
  Override options let you supply table addresses manually.

## Known limitations

- The Game Boy's PSG notes are written at equal-tempered pitch, although the hardware plays high
  notes slightly out of tune.
- The driver's echo is a feedback delay, which is approximated with the reverb send.
- A SoundFont player resamples more cleanly than the GBA's mixer.
- Unsupported commands stop the affected track and produce a warning.
- See "Accuracy" in the README for the details.
